# Security Policy

## Reporting a vulnerability

If you've found a security issue in Ronsel, please do not file a public issue.

Contact the maintainer privately:

- **Email**: uxopousa@gmail.com
- Or open a private security advisory on GitHub's "Report a vulnerability" button under the *Security* tab.

Please include:

- A description of the issue and its impact.
- Steps to reproduce.
- The affected version (commit SHA or release tag).

You will receive an acknowledgement within 5 business days.
