# Request

Cada usuario demo ahora crea su propio usuario único para evitar que compartan datos.

## Reasoning

El demo usaba un email fijo (demo@ronsel.app), por lo que todos los usuarios demo compartían la misma cuenta y veían los mismos datos. Ahora se genera un UUID por sesión, aislando los datos de cada persona.

## Output

- backend/src/services/auth.service.js: demoLogin() ahora crea un usuario con email demo-<uuid>@ronsel.app en lugar de usar uno fijo.
