# Request

Agrupar múltiples mejoras: bug hábitos calendario, responsive móvil, botones seed/wipe para desarrollo, y rediseño de vistas semana y 3 días.

## Reasoning

Se identificaron y corrigieron varios problemas de UI/UX:
- Los hábitos se tachaban en todos los días del calendario (solo debe ser hoy)
- Los hábitos aparecían en días pasados
- La UI móvil estaba mal adaptada (Tasks, Dashboard)
- No había forma de poblar/limpiar datos de prueba fácilmente
- Las vistas de semana y 3 días no mostraban bien las tareas en móvil ni desktop

## Output

### Backend
- `backend/src/services/dev.service.js` (nuevo): Seed/wipe de datos de prueba
- `backend/src/controllers/dev.controller.js` (nuevo): Controlador para dev routes
- `backend/src/routes/dev.routes.js` (nuevo): Rutas POST /api/dev/seed y /api/dev/wipe
- `backend/src/app.js`: Registro de rutas dev

### Frontend
- `frontend/src/pages/Dashboard.jsx`: 
  - Bug: hábitos solo se tachan en celda de hoy
  - Bug: hábitos solo aparecen en días actuales y futuros
  - Bug: anillo de día hoy se recortaba (fix: ring-inset)
  - Vista semana responsive: filas en móvil, grid en desktop
  - Vista 3 días responsive: filas en móvil, grid en desktop
  - Sin límites de tareas/hábitos visibles (ni "+N")
  - Contenedor más ancho (max-w-6xl)
  - Semana con scroll horizontal en desktop
- `frontend/src/pages/Tasks.jsx`: Barra de búsqueda y filtros responsive
- `frontend/src/components/layout/Layout.jsx`: Botones seed/wipe en sidebar
- `frontend/src/components/ui/Skeleton.jsx`: SkeletonDashboard actualizado a max-w-6xl
